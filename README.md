# Edge Image Classification
Lightweight CNN-based image classification designed for efficient deployment on resource constrained edge devices.

## Project files

- `src/` contains the project source code.
- `results/` contains training histories and the data split manifest.
- `plots/` contains generated training curves and sample images.

The dataset and trained model files are not included. The Intel Image Classification dataset is available on [Kaggle](https://www.kaggle.com/datasets/puneet6060/intel-image-classification).
